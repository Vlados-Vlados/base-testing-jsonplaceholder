# BaseTestingJsonplaceholder

### Описание:

Это проект для проработки автоматизации тестирования API сервиса в рамках обучения автоматизации тестирования API.
В проекте реализован небольшой API клиент, на основе которого выполняются тесты.
Цель: Проработать построение архитектуры проекта, проверить базовые навыки requests и pytest в связке и применить их для сборки цельного проекта по автоматизации тестирования API сервиса.
Проект построен на базе публичного фейкового REST API - JSONPlaceholder.

#### Цель:
Автоматизировать: 
* проверку CRUD-ресурса публичного REST API и заложить основу поддерживаемого тестового проекта: API-клиент, переиспользуемые фикстуры, точные проверки статус-кодов и структуры ответа.
* проверку ресурса с фильтрацией через query-параметры и закрепить работу с негативными контрактами: пустой результат фильтра, создание сущности без обязательного поля.

#### Критерии приемки:
* Корректность проверок: статус-коды соответствуют документации/фактическому поведению; проверки структуры и типов данных выполнены осмысленно.
* Полнота сценариев: покрыты все пункты из требований; для негативных кейсов есть комментарий с фактическим поведением API.
* Качество использования pytest: тесты оформлены как отдельные функции с говорящими именами; используются параметризация или фикстуры там, где это уместно (но без переусложнения).
* Организация кода: базовый URL и общие данные вынесены, но код не раздут лишними абстракциями.
* Независимость тестов: ни один тест не зависит от выполнения другого.

### Стэк/требования:

pytest 9.1.1
requests 2.34.2
